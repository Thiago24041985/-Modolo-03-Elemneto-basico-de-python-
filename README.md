# 🐍 Módulo 03 - Elementos Básicos de Python (Tratamento de Dados)

Repositório dedicado aos estudos, anotações práticas e exercícios do **Módulo 03**, focado nos fundamentos da linguagem Python aplicados à Ciência de Dados.

## 💡 Como elaborei este projeto

Estruturei este repositório para documentar minha evolução passo a passo nos conceitos iniciais do Python, dividindo o aprendizado entre teoria testada na prática e resolução de exercícios:

1. **Anotações e Testes em Jupyter Notebook (`Mod3Not1.ipynb` e `Mod3Not2.ipynb`):** Documentei os conceitos das aulas diretamente em células executáveis, testando cada comando na prática para observar o comportamento da linguagem, verificar os tipos de retorno (`type()`) e validar erros comuns (como *case sensitivity*).
2. **Prática e Fixação (`Mod03Ex01 - Python basico.ipynb` e `mod03ex02 instrucao.ipynb`):** Apliquei os conceitos estudados na resolução das listas de exercícios propostas, construindo os scripts passo a passo para consolidar a lógica de programação.

## 📚 Conteúdos Estudados e Implementados

### Aula 1 — Introdução e Operações Básicas
* **Fundamentos:** Conceito de linguagem de alto nível, papel do Python em Ciência de Dados e uso de ambientes como **Jupyter Notebook** e interpretador via prompt (Anaconda).
* **Python como Calculadora:** Operadores aritméticos (`+`, `-`, `*`, `/`, `**`) e ordem de precedência matemática com uso de parênteses.
* **Variáveis e Atribuição:** Operadores de atribuição simples e composta (`=`, `+=`, `-=`) e atribuição múltipla em uma única linha.

### Aula 2 — Tipos de Dados Primitivos e Lógica
* **Numéricos (`int` e `float`):** Diferenciação entre inteiros e pontos flutuantes, comportamento das divisões e conversões de tipo.
* **Textos (`str`):** Criação de cadeias de caracteres, concatenação, multiplicação de strings, indexação (`[0]`) e métodos nativos como `len()`, `upper()` e `print()`.
* **Booleanos (`bool`) e Lógica:** Valores `True` e `False`, operadores relacionais (`==`, `!=`, `>`, `<`, `>=`, `<=`) e operadores lógicos (`and`, `or`, `not`).

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* **Jupyter Notebook** (Anaconda / Google Colab)
